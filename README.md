# Incident Investigator

Интерактивный разбор тайм-аута оплаты в учебном магазине. В демо сохранены три записи локального стенда и вывод агента по одному расследованию. Все примеры заказов синтетические. Идентификаторы запросов позволяют сопоставить трейс с ответом клиенту.

Откройте `index.html` в браузере или разместите содержимое этой папки на статическом хостинге. Страница работает по относительным ссылкам и использует встроенные в браузер средства. Раскрывайте улики нажатием или клавишей Enter. Ссылка `#ev-0002` ведёт к записи о тайм-ауте оплаты.
